# freeCodeCamp Python Certification

My solutions to the workshops, labs and certification projects of the freeCodeCamp Python Certification.

## Getting Started
Run any file from the main folder:
```bash
python <folder>/<file>.py
```
Example:
```bash
python 01-python-basics/rpg_character_creator.py
```
